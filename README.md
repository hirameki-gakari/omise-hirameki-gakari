# お店のひらめき係

阿佐ヶ谷・高円寺エリアの実在店舗から、「今日は誰と」「今日はどんな気分か」を選ぶだけで一軒をひらめかせる、外食提案アプリ。

検索して比較するサービスではなく、悩まずに「今日はここでいいじゃん」と決められることを目指しています。姉妹サービスに「ごはんのひらめき係」(家のごはんを決める)があります。

## 構成

静的サイト(vanilla JS、ビルド不要)。GitHub Pages でそのまま公開できます。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面と、推薦ロジック(誰と×気分の絞り込み・採点・本命/穴場/冒険の選定) |
| `privacy.html` | プライバシーポリシー |
| `lib/open-hours.js` | 営業時間の文字列を読み取り、「今開いているか」(通常の営業時間にもとづく目安)を判定する |
| `lib/recommend.js` | 推薦の中身: 最低条件・採点・本命/穴場/冒険の選定・推薦理由・エリア/駅/席数/出典の表示用整形 |
| `data/restaurants.js` | 店舗の基本データ(名前・ジャンル・エリア・価格帯・性格 など) |
| `data/store-info.js` | 営業時間・定休日・席数、毎週の定休曜日(`closedWeekdays`)、**出典・最終確認日・注意書き(`src` `checked` `infoNote`)**、**提案から外す店(`STORE_CLOSED`)** |
| `data/store-contact.js` | 食べログURL・電話番号・住所・最寄り駅と距離・食べログの設備情報(お子様連れ・個室・カウンター席のみ) |
| `data/photos.js` | 自社撮影写真の対応表(`scripts/sync-photos.js` で生成) |

## 提案の条件(すべての枠で守る)

本命・穴場・冒険・ほかの候補の**すべて**が、次の最低条件を満たす店から選ばれます(`lib/recommend.js`)。「冒険」は、条件を外すのではなく、条件を満たす候補の中で意外なジャンルを選ぶ枠です。

- 誰との適性が3以上。気分ごとの最低条件: 飲みたい=お酒が中心の業態 / ゆっくり話したい=静かさ / 家族みんなで=家族適性・気軽さ・量(**子連れとは決めつけない**) / コスパ重視=一人あたりの予算上限**4,000円以下**(「安い」とは書かない) など
- 夜の外食の提案なので、**スイーツ専門店は対象外**。カフェ・喫茶は、夕方以降の営業が営業時間データで確認できる店だけ
- 今日の夕方(17〜22時)に営業がある店。営業時間が不明な店は除外しないが、順位を下げ、画面で「営業時間未確認」と示す
- 食べログの席数が**カウンター席のみ**の店は、家族向けにしない(確認できる事実による補正)
- 条件に合う店が足りないときは、黙って条件を外さない。1〜2軒なら件数を説明し、0軒のときだけ「条件をゆるめた近い1軒」を理由つきで示す
- 同じ条件での再提案では、直近の本命を選択肢から外す(候補が十分あるとき)

**推薦理由**は最大2件。店ごとの文(`reasonSeeds`)と、データにある事実(予算・営業時間・駅からの距離・席数・設備)だけを使います。評価点・口コミ件数・「安い」の断定は使いません。時間帯(24時間・深夜・ランチ・朝)や座敷・子連れ・個室の表現は、営業時間・席数・食べログの設備情報で裏付けられるときだけ出ます。

次のいずれかの店は提案に出ません(データは残ります)。

- `STORE_CLOSED` に載っている店(閉店・臨時休業・運営者の判断で除外)。再開したら、その行を消す
- 今日が毎週の定休日の店(`closedWeekdays`)。深夜0〜3時台は前日の曜日で判定
- 今日の営業がもう終わった店(閉店まで45分を切り、この後の営業もない店)。開店前の店は出る

「行き先」は、予約URL → 公式サイト → 食べログ → 地図の順で、ボタンの文言は実際の遷移先の名前(「食べログで詳細を見る」など)です。営業状況の表示は「通常の営業時間にもとづく目安」で、臨時休業・混雑・満席は保証しません。

## 店舗データの根拠

- 営業時間・席数には、出典(`official`=公式サイト / `tabelog`=食べログ掲載情報 / `web`)と最終確認日が付き、結果カードの詳細に表示されます。情報源同士が食い違う店・営業時間が確認できない店は、`infoNote` の注意書きで利用者に伝えます。
- 駅からの距離は食べログ掲載の**直線距離**をそのまま表示します。徒歩分数は推測で作りません。
- 席数は合計だけを「目安」として表示します(内訳の書き方は情報源ごとに違い、合計と合わないことがあるため)。
- 設備・子ども向けなどの表現は、食べログの設備情報で確認できたものだけを使います。現地確認はしていません。
- 電話番号は固定電話だけを載せます。携帯電話(070/080/090)・IP電話(050)は、お店の個人の番号の可能性があるため載せません(該当店の「電話する」ボタンは出ません)。

## テスト

```
node tests/run-all.cjs          # すべて実行(データやコードを変えたら、公開の前に)
```

| テスト | 確認すること |
|---|---|
| `closed-today.cjs` | 全曜日×時間帯×全パターンで、閉店・定休日・営業終了の店が提案に混ざらない。除外リストが有効。`STORE_INFO` にid重複がない |
| `recommend.cjs` | 全枠(本命・穴場・冒険・ほかの候補)が最低条件を満たす。指摘された具体例(和菓子店・担々麺・カフェ・4,000円超)の回帰。候補不足時に条件を黙って外さない。理由の断定に根拠がある。連続再提案で同じ本命が続かない |
| `data-integrity.cjs` | 断定(24時間・ランチ・座敷・子連れ等)と営業時間・設備の裏付け、駅・距離、重複、出典・確認日。個別に訂正した店の回帰 |
| `open-hours.cjs` | 営業時間の読み取りと今の営業判定(日またぎ・昼夜2部・曜日の並記など)。実データの読み取り率 |
| `links.cjs` | 行き先の優先順位、電話番号・住所・食べログURLの形式 |
| `privacy.cjs` | プライバシーポリシーの記載と、サイトの実際の挙動が一致している |
| `reroll-copy.cjs` | 「別のお店をひらめく」後のひらりのセリフ選び(直近3回を避ける・ジャンル別) |
| `seo.cjs` | title・description・canonical・OGP・構造化データ・見出し・sitemap・robots・サイト内リンク。実態と違う表現(位置情報の「近く」など)や架空の評価を入れていないこと |
| `check-store-status.cjs` | 下記の確認スクリプトの検知ロジック(通信はモック) |

推薦理由の使い回しの監査は `node scripts/audit-reasons.js`。

## 定期メンテナンス(月1回を目安に)

閉店・移転は今後も起きるので、放置するとデータが古くなります。

```
node scripts/check-store-status.js --out report.md
```

食べログのページを読み取り(約10〜15分。データは書き換えません)、次を報告します。

1. **閉店・移転・休業の表示が出た店** → `STORE_CLOSED` への追記候補も表示される
2. **最新の口コミが8か月以上前の店** → 閉店の疑い。現地・公式SNSで確認してから判断する
3. **電話番号・住所が変わった店** → `data/store-contact.js` を更新(移転なら店名・エリア・最寄駅も見直す)

終了コードは、1か3があれば2、なければ0です。食べログの表示は遅れることがあるので、閉店の最終判断は、現地・公式SNS・電話などで確認してください。

## 検索エンジン(SEO)

| 項目 | 内容 |
|---|---|
| 公開URL | `https://hirameki-gakari.github.io/omise-hirameki-gakari/`(canonical もこのURL。ルートドメインやごはんのひらめき係とは別のURL) |
| title / description | サービス名で始め、対象エリア(阿佐ヶ谷・高円寺)と何のサービスかが分かる文にする。このサービスは現在地(位置情報)を使わないので、「近くの」などとは書かない |
| 初期HTML | JavaScriptを実行しなくても、`h1`(サービス名を含む)と「お店のひらめき係とは？」の説明が読める。店舗データはJavaScriptで描画されるため、検索エンジンに読ませたい説明は初期HTMLに書く |
| OGP画像 | `assets/og-image.png`(1200x630)。ファビコン・ホーム画面アイコンは `assets/favicon-*.png` `assets/apple-touch-icon.png`。いずれも現行デザインのひらり |
| 構造化データ | `WebSite` と `WebApplication` のみ。評価・レビュー・運営会社情報など、裏付けのない項目は入れない(`tests/seo.cjs` が検査) |


Google Search Console での登録・sitemap送信などは、人が行う作業です(所有権確認にGoogleアカウントでのログインが必要)。

## データの取り扱い

店舗情報は、食べログ等の公開情報や各店の公式情報をもとにまとめており、現地確認はしていません(取得日: 2026-09-19)。営業時間・価格は変わることがあるため、画面上でも「最新は各店の公式情報で」と案内しています。設計上の基準は `RECOMMENDATION.md`、ブランドの決まりは `BRAND.md` を参照してください。
