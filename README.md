# お店のひらめき係

阿佐ヶ谷・高円寺エリアの実在店舗から、「今日は誰と」「今日はどんな気分か」を選ぶだけで一軒をひらめかせる、外食提案アプリ(MVP)。

検索して比較するサービスではなく、悩まずに「今日はここでいいじゃん」と決められることを目指しています。姉妹サービスに「ごはんのひらめき係」(家のごはんを決める)があります。

## 構成

- `index.html` 1ファイルで完結する静的サイト(vanilla JS、ビルド不要)
- GitHub Pages でそのまま公開できます

## 店舗データについて

店舗名・ジャンル・エリアは公開情報をもとにまとめていますが、営業時間・電話番号・正確な住所までは確認できていません。実際に行く際は各店舗の公式情報でご確認ください。
