# 店舗写真の追加方法

## 手順

1. このフォルダ(`photos/`)に、写真を **店舗id.jpg** という名前で置く
   - 店舗idは `data/restaurants.js` の `id:"..."` と完全に一致させる
   - 例: 「リストランテ impronte」(id: `asagaya-impronte`) → `photos/asagaya-impronte.jpg`
   - 拡張子は `.jpg` `.jpeg` `.png` `.webp` に対応
   - 1店舗につき1枚(複数枚には今のところ非対応)
2. ターミナルでこのプロジェクトのフォルダに移動し、次を実行:
   ```
   node scripts/sync-photos.js
   ```
3. `data/photos.js` が自動更新される
4. `index.html` を開いて、その店が「今日のひらめき」に出たときに写真が表示されることを確認する
5. 問題なければ commit & push して公開

## 撮影のコツ

- **明るい時間帯・自然光**で撮る(暗い写真は避ける)
- 横向き(横長)で撮ると画面にきれいに収まる
- 迷ったら優先順位は「外観 > 内観・雰囲気 > 料理」。まずは「ここに来たらどんな夜になるか」が伝わる1枚を
- お客さんや店員さんが写り込む場合は、写真の使用について一言断っておくと安心
- ファイルサイズの目安は1枚あたり300〜800KB程度(スマホで撮った写真をそのまま使ってOKなことが多い)

## 権利について

- ここに置く写真は、**自分で撮影したもの**を前提にしています(`source:"self"`として記録されます)
- 食べログ・Instagram・Googleマップ等、他者が撮影した写真を無断で保存しないでください
- 店舗から写真提供を受けた場合は、扱いが変わるので追加してから相談してください(`data/photos.js`の`source`を`"provided_by_store"`等に変更し、`credit`欄にクレジット表記を入れます)
